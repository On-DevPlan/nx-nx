# A01 · 加一个页面（面板侧）

> 本文只管**前端页面**。要加后端能力（action → CLI + HTTP）见主项目 README 的「新增功能域」。
> 两件事互不强制：一个页面可以完全不调 action（见 `views/board/`）。

## 结论先看

**加一个页面 = 新建一个目录，不改任何全局文件。**

```
src/web/frontend/views/<名>/
  route.ts     ← 必须有：身份与摆法
  page.tsx     ← 必须有：组件（默认导出）
  api.ts       ← 建议有：本页对 action 的调用收口
  components/  ← 可选：本页私有组件
```

页面 id 就是 `<名>`（目录名）。路由由 `app/router.tsx` 里的 `import.meta.glob` 自动发现，
不需要去任何注册表登记。

## 三步

### 1. 写 `route.ts`

```ts
import { definePage } from '../../app/route.js';

export default definePage({
  path: '/repos',                       // 必须以 / 开头；hash 路由里 # 之后的部分
  nav: { label: '仓库', order: 30 },     // 省略整个 nav 字段 = 这个页面不进导航
  layout: 'app',                         // 省略则 'app'；可选值见 app/layouts.ts
  page: () => import('./page.js'),       // 必须是函数，Vite 才保得住按页代码分割
});
```

三个字段的取舍：

| 想做的事 | 怎么写 |
| --- | --- |
| 出现在导航里 | 写 `nav: { label, order }` |
| 不进导航（详情页 / 向导步骤 / 全屏页） | **不写 `nav`**，配 `path: '/repos/:id'` |
| 换成左侧栏版式 | `layout: 'sidebar'`（或你新加的壳） |

### 2. 写 `page.tsx`

```tsx
export default function ReposPage() {
  return <div className="stack" style={{ padding: 16 }}>…</div>;
}
```

- 需要路由参数：`const { id } = useParams<{ id: string }>()`
- 需要跳转：`<Link to="/repos/xxx">` 或 `useNavigate()`
- 筛选 / 分页 / 选中项**不要放 useState**，放 `useSearchParams()`——刷新、分享、后退都会用上
- 复用组件从 `../../components/` 取（`ui.jsx` 有 `Card` 风格的原子类、toast、dialog、ErrorBoundary）

### 3. 需要后端数据时写 `api.ts`

```ts
import { useStore } from '../../store.js';

export function useReposApi() {
  const { client } = useStore();
  return {
    list: () => client['repo.list']({}),
  };
}
```

`client['<action id>']` 的参数与返回值类型由后端注册表推出，写错在编译期就红。
**页面里不要裸写 `fetch` / `api()`** —— 那会绕过类型契约（这条有 eslint 兜底）。

## 加一种新版式（左侧栏 / 分栏 / 全屏）

1. 新建 `app/shells/<X>Shell.tsx`，里面放 `<Outlet />`，内容用 `useNav()` 折出导航
2. `app/layouts.ts` 的 `LAYOUTS` 加一行 `<x>: <X>Shell`
3. 目标页面 `route.ts` 写 `layout: '<x>'`

既有页面**一行都不用改**。`app/shells/SidebarShell.tsx` 就是照这个做的现成例子。

## 验证

```bash
pnpm typecheck                     # 类型
node --import tsx --test tests/unit/views.test.mjs   # 路由声明：path 唯一、page 是函数
pnpm dev                           # 打开面板，看导航与深链
```

## 常见错误

| 现象 | 原因 |
| --- | --- |
| 页面不出现 | 目录里没有 `route.ts`（或文件名拼错），`import.meta.glob` 只认 `views/*/route.ts` |
| 导航里有、点进去空白 | `page` 不是函数（写成了 `import(...)` 的值），代码分割点丢了 |
| 出现在顶栏壳里，但想要侧栏 | `route.ts` 里没写 `layout`，默认是 `app` |
| 加页面后 `pnpm typecheck` 红在深链 | 用了不存在的路由参数名；`useParams` 的键要和 `path` 里的 `:xxx` 完全一致 |
| 刷新 404 | 用了 BrowserRouter 风格的链接；这里必须用 hash 路由（静态服务没有 SPA fallback） |
