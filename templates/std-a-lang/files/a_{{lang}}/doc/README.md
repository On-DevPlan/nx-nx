# a_{{lang}} · {{lang}}

本目录是该语言的**命名空间根**，遵循 `a_{语言}/{sdk, proj, res, doc}` 四象限约定。

## 四象限

| 目录 | 用途 | 典型内容 |
| --- | --- | --- |
| `sdk/`   | 自研 / 二次封装的 SDK、客户端 | 协议封装、内部库、对外 API 包装 |
| `proj/`  | 该语言下的项目 | 实际可运行项目，建议统一前缀（`nx-` / `pg-` / `go-` …） |
| `res/`   | 第三方仓库、参考资料、下载资源 | clone 下来的开源项目、归档、工具 |
| `doc/`   | 工具链笔记、规范、最佳实践 | 本目录、踩坑记录、风格指南 |

## 何时新增目录

四象限不够用时再考虑扩展，但请保持**扁平和语义清晰**。例如：
- 临时实验 → 在 `proj/<name>/scratch/` 内
- 下载归档 → `res/_downloads/`
- 不确定放哪 → 默认进 `proj/`，再观察

## 跨象限引用

- `proj/` 引用 `sdk/`：建议走 git submodule 或 pnpm workspace，不要直接相对路径软链
- `proj/` 引用 `res/`：通常作为参考资料，不参与构建；如需参与构建应迁到 `sdk/`
